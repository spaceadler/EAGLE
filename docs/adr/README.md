# adr

← [README](../../README.md)

The Architecture Decision Records of EAGLE's Phase A study, one file per decision, taken in the order
[ADR-00](ADR-00-process.md) sets out: vehicle and scope ([ADR-01](ADR-01-mission-profile.md)), fault model
and redundancy pattern ([ADR-02](ADR-02-fault-tolerance.md)), hardware/software split and FPGA budget
([ADR-03](ADR-03-partitioning.md)), inter-chip links ([ADR-04](ADR-04-interchip-icd.md)), flight software
stack ([ADR-05](ADR-05-flight-software.md)), and HDL and verification ([ADR-06](ADR-06-hdl-verification.md)).
Statuses live in one place, the [index in the README](../../README.md#decision-records); ADR-00 defines
what each status means and that only the owner accepts a decision.
